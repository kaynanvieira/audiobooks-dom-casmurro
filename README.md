#Audiobooks - Dom Casmurro

Projeto desenvolvido na criação de um tocador de áudio interativo web para o audiobook da obra *Dom Casmurro*, de Machado de Assis.

---

## 🚀 Funcionalidades

- **Play / Pause:** Controle de reprodução da faixa com alteração visual do botão.
- **Navegação de Capítulos:** Botões para avançar para o próximo capítulo ou retornar ao anterior (com rotação automática entre os 10 capítulos disponíveis).
- **Auto-advance:** Troca automática para o próximo capítulo ao finalizar o áudio atual.
- **Atualização Dinâmica:** Troca do título do capítulo na interface conforme o áudio em reprodução.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura semântica e tags de áudio/SVG.
- **CSS3:** Estilização responsiva, layout em Flexbox e gradientes.
- **JavaScript (ES6):** Manipulação da DOM e lógica de controle dos áudios.
